# Portfolio Project Standard

Every promoted AI/ML project should answer these questions:

1. What problem does it solve?
2. What data does it use?
3. What is the architecture?
4. Why were these technologies selected?
5. How is the project reproduced locally?
6. How is the model evaluated?
7. What are the known limitations?
8. How would the system be improved for production?
9. Where is inference separated from training?
10. How are secrets and generated artifacts handled?

## LinkedIn-ready project checklist

- Clear project name
- One-sentence value proposition
- Architecture or pipeline
- Technology stack
- Dataset/source description
- Metrics or honest evaluation status
- Demo/API instructions
- Limitations
- Future improvements
- Screenshot or demo GIF when available
- Link back to the repository

Do not invent metrics. If an experiment has no reliable benchmark, say so explicitly.
