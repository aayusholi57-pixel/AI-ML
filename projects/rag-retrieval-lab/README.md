# RAG Retrieval Lab

## Portfolio summary

A collection of retrieval experiments exploring PDF ingestion, text chunking, TF-IDF retrieval, dimensionality reduction, semantic search, and RAG generation.

## Engineering focus

- Document ingestion
- Chunking strategies
- TF-IDF retrieval
- TruncatedSVD
- Vector normalization
- Cosine-similarity ranking
- Grounded LLM generation
- Retrieval source metadata

## Production direction

The maintained Exam Preparation RAG under Student rags is the recommended implementation. The notebooks in the learning archive document experimentation and iteration.

## Recommended LinkedIn framing

**Developed a retrieval-augmented generation pipeline for study material, covering document ingestion, chunking, vector retrieval, source-aware context construction, and grounded Gemini generation. Focused on reproducibility, validation, and transparent retrieval sources.**
