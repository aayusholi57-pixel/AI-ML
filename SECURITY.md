# Security Policy\n\n## Reporting a vulnerability\n\nPlease do not publish credentials, API keys, private data, or exploit details in a public issue.\n\nFor a genuine security concern, contact the repository owner privately through GitHub.\n\n## Repository safety rules\n\n- Never commit real API keys or tokens\n- Never commit `.env` files\n- Do not commit local databases or vector-store directories\n- Do not commit Python caches or notebook checkpoints\n- Do not commit generated model artifacts unless they are intentionally released\n- Rotate any credential that may have been exposed\n
