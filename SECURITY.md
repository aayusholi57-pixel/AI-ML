# Security Policy

## Reporting a vulnerability

Please do not publish credentials, API keys, private data, or exploit details in a public issue.

For a genuine security concern, contact the repository owner privately through GitHub.

## Repository safety rules

- Never commit real API keys or tokens
- Never commit `.env` files
- Do not commit local databases or vector-store directories
- Do not commit Python caches or notebook checkpoints
- Do not commit generated model artifacts unless they are intentionally released
- Rotate any credential that may have been exposed
