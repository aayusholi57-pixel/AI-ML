# Portfolio Map

This repository is both a learning record and an engineering portfolio.

## Start here

1. Read the root README
2. Review the maintained FastAPI example
3. Explore the focused project folders
4. Open notebooks for the underlying experiments
5. Check each project's own README before running it

## Engineering progression

The repository contains work across these layers:

- Python programming and problem solving
- Data analysis and visualisation
- Classical machine learning
- Neural networks and deep learning
- Computer vision
- Natural language processing
- Generative AI and LLM applications
- Retrieval-Augmented Generation
- Semantic search and vector databases
- API and application development

## Maintenance standard

New portfolio projects should aim to include:

- A clear README
- Reproducible dependencies
- Small, understandable modules
- Input validation
- Tests for important behaviour
- No secrets or local databases
- No generated model weights unless intentionally released
- A short explanation of architecture, data, evaluation, and limitations

Educational experiments may remain lightweight. They should not be presented as production systems unless they have been tested and documented accordingly.
